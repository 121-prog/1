# Трекер прочитанных книг 📚

Консольное приложение на Python для учета прочитанных книг. Позволяет добавлять книги, просматривать список, анализировать оценки и статистику по авторам.

## Возможности

- ✅ Добавление книг с указанием автора, названия, оценки и даты прочтения
- ✅ Просмотр всех добавленных книг
- ✅ Расчет средней оценки всех книг
- ✅ Статистика по авторам (количество книг каждого автора)
- ✅ Удаление книг из списка
- ✅ Проверка на дубликаты (автор + название)
- ✅ Сохранение данных в JSON-файл

## Требования

- Python 3.6 или выше
- Никаких дополнительных библиотек не требуется (используются только стандартные модули)
